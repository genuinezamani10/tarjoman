# ترجمان — Tarjoman

**ترجمهٔ PDF به فارسی** — یک ورک‌فلوی آماده برای دستیار Muse که هر PDF (مقاله، کتاب درسی، رمان — حتی **اسکن‌شده**) را می‌گیرد و یک **PDF فارسی راست‌به‌چپ** (با فونت وزیرمتن) به همراه نسخهٔ Markdown تحویل می‌دهد.

## امکانات

- **سه حالت ترجمه** برای سه نوع متن (جدول پایین)
- **OCR کاملاً لوکال** برای PDFهای اسکن‌شده با [Indra OCR](https://huggingface.co/datalab-to/indra-ocr) — روی CPU، بدون GPU، بدون ارسال فایل به هیچ سرویس ابری
- **نرمال‌ساز فارسی** که خطاهای رایج OCR راست‌به‌چپ را اصلاح می‌کند (مثلاً «بہتر» ← به‌تر، «رفيق» ← رفیق)
- **واژه‌نامهٔ زنده**: اصطلاحات و نام‌های خاص هر سند اول استخراج و در همهٔ تکه‌ها یکدست ترجمه می‌شوند
- **کنترل کیفیت دو مرحله‌ای** (بازبینی زبان و ظاهر) + کنترل تمامیت با شمارش کلمات؛ تکه‌های مشکوک علامت‌گذاری می‌شوند، دور انداخته نمی‌شوند
- استخراج قطعی متن با PyMuPDF: تشخیص دوستونه، حذف سرصفحه/پاصفحهٔ تکراری، تکه‌بندی روی مرز پاراگراف

## سه حالت ترجمه

| حالت | ورودی (`mode`) | مناسب برای | ویژگی |
|---|---|---|---|
| مقاله | `article` (پیش‌فرض) | مقاله و متن علمی | ترجمهٔ روان و علمی؛ معادل انگلیسی اصطلاح فقط در نخستین کاربرد |
| درسی | `textbook` | کتاب و جزوهٔ درسی | حفظ ساختار مثال‌ها، تمرین‌ها و فرمول‌ها؛ لحن آموزشی |
| رمان | `novel` | داستان و رمان | نثر قصه‌گو (محاوره‌ایِ معیار)؛ راهنمای سبک قابل شخصی‌سازی با نمونهٔ نثر دلخواه (`style_sample`) |

## چطور کار می‌کند؟

```
PDF ──► استخراج متن (PyMuPDF) ──► اگر اسکن‌شده بود: OCR لوکال (Indra)
    ──► نرمال‌سازی فارسی ──► واژه‌نامهٔ زنده ──► ترجمهٔ تکه‌به‌تکه
    ──► بازبینی زبان و ظاهر ──► مونتاژ با اسکریپت ──► PDF + Markdown
```

## OCR لوکال (Indra)

- مدل ONNX یک‌میلیون‌پارامتریِ Datalab؛ دانلود مدل‌ها حدود **۷۶ مگابایت** (فقط بار اول)
- فقط CPU — روی یک ماشین ۲ هسته‌ای حدود **۰٫۵ ثانیه به‌ازای هر صفحه**
- پشتیبانی از ۸۰+ زبان از جمله **فارسی** (مدل اختصاصی خط راست‌به‌چپ)، تشخیص چیدمان و ترتیب خواندن ستون‌ها
- محدودیت‌ها: دست‌نویس و اسکن‌های خیلی خراب ضعیف خوانده می‌شوند و جدول‌های پیچیده ممکن است به‌هم بریزند؛ برای چاپ تمیز عالی است

## نصب

پیش‌نیاز: محیط **Muse** (این پروژه یک ورک‌فلوی Muse است؛ ترجمه را مدل زبانی همان محیط انجام می‌دهد و **هیچ API Key جداگانه‌ای لازم نیست** — جزئیات در بخش سؤالات پرتکرار) و **Python 3.10+**.

۱. فایل `tarjoman.js` را در پوشهٔ ورک‌فلوها بگذارید (`~/.jarvis/workflows/`).

۲. پوشهٔ `scripts/` را در مسیر زیر کپی کنید:

```
~/workspace/workflows/tarjoman/scripts/
```

۳. راهنماهای سبک را سر جایشان بگذارید:
   - `styles/style-guide-novel.md` ← `~/workspace/workflows/tarjoman/`
   - `styles/tarjoman-article-style.md` و `styles/tarjoman-novel-glossary.md` ← حافظهٔ دستیار (`~/memory/`)

۴. محیط مجازی OCR را بسازید:

```bash
python3 -m venv ~/workspace/tools/indra-venv
~/workspace/tools/indra-venv/bin/pip install -r requirements.txt
```

(مدل‌های Indra در اولین اجرای OCR به‌صورت خودکار دانلود و کش می‌شوند.)

## استفاده

PDF را برای دستیار بفرستید و بگویید: **«ترجمان اجراش کن»** — یا ورک‌فلو را مستقیم با این ورودی‌ها اجرا کنید:

| ورودی | توضیح |
|---|---|
| `pdf_path` | مسیر PDF (اجباری) |
| `mode` | `article` \| `textbook` \| `novel` (پیش‌فرض: `article`) |
| `pages` | بازهٔ صفحات، مثل `1-5` (اختیاری؛ خالی یعنی همه) |
| `title` | عنوان دلخواه خروجی (اختیاری) |
| `style_sample` | نمونهٔ نثر دلخواه برای حالت رمان (اختیاری) |
| `output_name` | نام فایل خروجی (اختیاری) |

## ساختار پروژه

```
tarjoman.js              ورک‌فلوی اصلی (استخراج → ترجمه → مونتاژ → بازبینی)
scripts/
  ocr_extract.py         مرحلهٔ OCR اسکن‌ها: برش صفحات، Indra، پاک‌سازی، تکه‌بندی
  fa_normalize.py        نرمال‌ساز فارسی خروجی OCR (نیم‌فاصله، ارقام، نویسه‌های اردو/عربی)
styles/
  style-guide-novel.md        راهنمای سبک رمان
  tarjoman-article-style.md   راهنمای سبک و واژگان مقاله
  tarjoman-novel-glossary.md  واژگان ترجیحی رمان
requirements.txt         وابستگی‌های Python مرحلهٔ OCR
```

## سؤالات پرتکرار

**آیا برای استفاده باید API Key بگیرم یا به یک API وصلش کنم؟**
نه. ترجمان یک ورک‌فلوی Muse است و کلید API ندارد. ترجمه را مدل زبانی‌ای انجام می‌دهد که محیط Muse شما با آن وارد شده‌اید (اشتراک یا دسترسی Muse خودتان). تنها چیزی که از اینترنت دانلود می‌شود، مدل‌های Indra OCR (حدود ۷۶ مگابایت) در اولین اجراست.

**آیا فایل‌های من به اینترنت می‌روند؟**
مرحلهٔ OCR، استخراج متن و مونتاژ کاملاً روی دستگاه خودتان انجام می‌شود و فایل به هیچ سرور ثالثی ارسال نمی‌شود. اما متن استخراج‌شده برای ترجمه در اختیار مدل زبانی محیط Muse قرار می‌گیرد — درست مثل هر گفت‌وگوی معمول با Muse. اگر سندتان محرمانه است، این نکته را در نظر بگیرید.

**روی ویندوز کار می‌کند؟**
Indra OCR رسماً روی لینوکس (x86_64 و ARM) و macOS (Apple Silicon) تست شده است؛ ویندوز در فهرست تست‌شده‌ها نیست و ممکن است کار کند، ولی تضمینی نیست.

**PDF من دست‌نویس یا اسکن کهنه است؛ جواب می‌دهد؟**
OCR دست‌نویس و اسکن‌های فرسوده پشتیبانی می‌شوند ولی کیفیتشان به‌مراتب پایین‌تر از چاپ تمیز است. ترجمان برای کتاب و مقالهٔ چاپی طراحی شده است.

**می‌توانم سبک ترجمهٔ رمان را عوض کنم؟**
بله؛ هنگام اجرا یک نمونه نثر از سبک دلخواهتان بدهید (`style_sample`) یا فایل `styles/style-guide-novel.md` را ویرایش کنید.
